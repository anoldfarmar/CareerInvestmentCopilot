AI简历优化与面试训练助手移动端前端开发指南

技术方向：TypeScript + React + Vite + Mobile First

1. 项目目标

请基于已生成的手机 APP 前端设计图，开发一个移动端优先的 AI 求职辅助前端应用，产品名称暂定为：

AI求职助手 / AI简历优化与面试训练助手

该应用主要服务于正在准备求职、实习、转行或面试的用户，提供以下核心功能：

简历上传、解析与优化建议。
根据简历和岗位 JD 生成个性化简历优化方案。
AI 模拟面试，包括通用面试、岗位专业面试、行为面试、压力面试、英文面试。
对话式面试训练，支持文字输入和语音输入的预留。
面试结束后生成结构化复盘报告。
管理求职投递链接、岗位状态、备注信息。
个人中心支持求职身份、目标岗位方向、训练偏好配置。

前端只负责页面、交互、状态管理、接口封装和 Mock 数据。后端 AI、RAG、文件解析、大模型生成、语音转写等能力通过预留 API 接口对接。

2. 技术选型
2.1 主框架

使用以下技术栈：

React + TypeScript + Vite + React Router + TanStack Query + Zustand + Ant Design Mobile

推荐原因：

使用 Vite 作为构建工具，适合快速创建 React + TypeScript 项目，并且官方文档支持通过 create vite 初始化应用。
使用 React Router 管理页面路由。React Router 当前文档提供多种路由模式，适合普通 SPA，也可逐步扩展到 Data Mode 或 Framework Mode。
使用 TanStack Query 管理服务端状态，包括简历列表、优化建议、面试会话、复盘报告、投递链接等异步数据；它适合处理请求缓存、重新获取和服务端状态同步。
使用 Zustand 管理轻量级客户端状态，例如当前用户配置、当前简历 ID、当前面试会话 ID、UI 状态、草稿内容等；官方文档提供基于 React hooks 的 store API。
使用 Ant Design Mobile 作为移动端基础组件库。它定位为移动 Web 应用的组件库，适合本项目的表单、弹窗、列表、按钮、Toast、Tabs 等移动端交互。
使用 React Hook Form + Zod 处理表单与校验。React Hook Form 适合减少表单重渲染，Zod 是 TypeScript-first 的 schema 校验库。
如果后续需要打包为 iOS / Android 原生容器，可使用 Capacitor 把 Web 应用包装为跨平台 App；Capacitor 官方定位为面向 Web 应用的原生运行时，可创建 iOS、Android 和 PWA 应用。

页面目标

模拟真实面试场景，AI 面试官逐步提问，用户通过文字或语音回答。

对话消息类型
type InterviewMessageRole = "assistant" | "user" | "system";

type InterviewMessage = {
  id: string;
  sessionId: string;
  role: InterviewMessageRole;
  content: string;
  createdAt: string;
  questionId?: string;
  audioUrl?: string;
  isStreaming?: boolean;
};
交互规则
进入页面后加载当前 session。
如果没有第一题，调用接口生成第一题。
用户点击“发送回答”后：
先把用户回答插入本地消息列表。
调用后端提交回答接口。
后端返回下一题、追问或阶段切换信息。
AI 回复支持流式展示预留：
如果 VITE_ENABLE_SSE=true，使用 SSE。
否则使用普通 HTTP response。
用户点击“结束面试”：
二次确认。
调用结束接口。
跳转到面试进度页或报告生成页。
底部输入区状态
默认：显示文字输入和语音按钮
录音中：显示波形、录音时长、取消、完成
发送中：输入区禁用，按钮 loading
面试结束：隐藏输入区，显示生成复盘报告按钮

20. 流式输出预留

AI 面试官回复和报告生成可以支持 SSE。

20.1 SSE 工具函数
export type StreamMessageHandler = {
  onMessage: (text: string) => void;
  onDone?: () => void;
  onError?: (error: Event) => void;
};

export function createSSEConnection(
  url: string,
  handlers: StreamMessageHandler,
) {
  const eventSource = new EventSource(url, {
    withCredentials: true,
  });

  eventSource.onmessage = (event) => {
    if (event.data === "[DONE]") {
      handlers.onDone?.();
      eventSource.close();
      return;
    }

    handlers.onMessage(event.data);
  };

  eventSource.onerror = (error) => {
    handlers.onError?.(error);
    eventSource.close();
  };

  return eventSource;
}
20.2 前端展示规则
SSE 开始：显示 AI 正在输入
每次 message：追加到最后一条 AI 消息
DONE：取消 loading
错误：Toast 提示，可点击重试
