# AI求职助手前端项目交付总结

## 项目概述

本项目基于 `开发框架.md` 的要求开发，是一个移动端优先的 AI 求职辅助前端应用，覆盖简历优化、模拟面试、面试复盘、投递链接管理和个人偏好配置等核心场景。

产品名称：AI求职助手

技术方向：TypeScript + React + Vite + Mobile First

## 技术栈

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Zustand
- Ant Design Mobile
- Axios
- React Hook Form
- Zod
- CSS Modules + CSS Variables
- 本地 Mock 数据
- Vitest

## 已实现功能

### 1. 全局移动端框架

- 移动端优先布局，适配 375px 基准宽度
- 顶部 `MobileHeader`
- 底部固定 `BottomTabBar`
- 页面级 `AppShell`
- 支持 safe-area
- 一级页面显示底部 Tab
- 二级页面支持返回按钮并隐藏底部 Tab
- 全局 CSS 变量、reset、通用工具样式

### 2. 路由系统

已实现以下路由：

- `/` 首页
- `/resume-optimize` 简历优化页
- `/resume-optimize/:resumeId` 简历分析结果入口
- `/resume-optimize/:resumeId/suggestions` 简历优化建议页
- `/resume-optimize/:resumeId/compare` 简历优化前后对比页
- `/mock-interview/setup` 模拟面试设置页
- `/mock-interview/:sessionId/chat` 模拟面试对话页
- `/mock-interview/:sessionId/progress` 模拟面试进度页
- `/review-report` 面试复盘报告列表页
- `/review-report/:reportId` 面试复盘报告详情页
- `/link-manage` 投递链接管理页
- `/profile` 个人中心
- `*` 404 页面

### 3. 首页

- 展示求职准备 KPI
- 展示三条核心路径：
  - 上传简历并优化
  - 开始模拟面试
  - 查看面试复盘
- 支持跳转到对应功能页面
- 提供辅助入口：
  - 投递链接管理
  - 个人求职模式
  - 最近一次面试报告

### 4. 简历优化模块

- 支持上传 PDF / Word 简历文件
- 文件格式校验：`.pdf`、`.doc`、`.docx`
- 文件大小限制：10MB
- 支持选择目标岗位方向
- 支持粘贴岗位 JD
- 使用 React Hook Form + Zod 做表单校验
- 点击开始分析后展示 loading 状态
- Mock 简历上传接口
- Mock 简历分析接口
- 展示分析指标：
  - 简历完整度
  - 关键词匹配度
  - 内容表达质量
  - ATS 友好度
- 展示优化建议 Tab：
  - 结构分析
  - 关键词
  - 经历改写
  - ATS 检查
- 支持一键生成优化版本
- 支持优化前 / 优化后 / 对比视图
- 导出优化版本接口已预留

### 5. 模拟面试模块

- 支持选择面试类型：
  - 通用面试
  - 岗位专业面试
  - 行为面试
  - 压力面试
  - 英文面试
- 支持关联最近简历
- 支持粘贴岗位 JD
- 支持设置题目数量：5 / 8 / 10
- 支持开启追问
- 支持语音输入开关
- 支持中文 / 英文面试语言
- Mock 创建面试会话接口
- 聊天式面试页面
- AI 面试官消息在左侧
- 用户回答消息在右侧
- 支持文字回答
- 支持语音输入前端状态预留
- 提交回答后 Mock 返回追问或下一题
- 支持结束面试确认
- 支持跳转到面试进度页

### 6. 面试进度模块

- 展示当前阶段
- 展示当前题数 / 总题数
- 展示进度条
- 展示已用时长
- 展示平均回答时长
- 展示回答总字数
- 展示题目类型分布
- 支持继续面试
- 支持生成复盘报告

### 7. 面试复盘模块

- 报告列表页
- 报告详情页
- 总评分圆环
- 综合评价
- 评分维度雷达图
- 逐题复盘：
  - 面试问题
  - 用户原回答
  - AI 点评
  - 存在问题
  - 优化建议
  - 参考回答
- 后续训练建议
- 支持再练一次

### 8. 投递链接管理

- 移动端卡片列表
- 支持状态筛选：
  - 全部
  - 待投递
  - 已投递
  - 面试中
  - Offer
  - 未通过
- 支持新增投递链接
- 支持编辑投递链接
- 支持删除投递链接
- 字段包括：
  - 公司名称
  - 岗位名称
  - 投递链接
  - 状态
  - 备注
- 使用 Zod 做表单校验
- 使用 Popup 做移动端底部表单

### 9. 个人中心

- 展示用户信息
- 支持设置求职身份：
  - 应届生模式
  - 转行模式
  - 有经验求职者模式
- 支持设置目标方向：
  - 技术岗
  - 产品岗
  - 运营岗
  - 数据分析
  - 设计岗
  - 市场岗
- 支持设置训练偏好：
  - 默认面试语言
  - 默认题目数量
  - 是否开启语音输入
  - 是否显示 STAR 提示
- Mock 用户配置读取和保存接口

### 10. API 与状态管理

- 所有业务接口均封装在 `src/features/*/api.ts`
- 所有服务端数据通过 TanStack Query 管理
- 客户端轻量状态通过 Zustand 管理
- Mock 数据放在 `src/features/*/mock.ts`
- 已预留 Axios HTTP Client
- 已预留 Authorization Header
- 已预留 SSE 工具函数
- 已预留语音转写服务函数

### 11. v1.1 真实面试知识库

- 复盘页支持切换“模拟面试复盘”和“真实面试复盘”
- 支持创建任意命名的领域 / 岗位知识库
- 支持在知识库中沉淀多场真实面试
- 支持上传真实面试录音
- 支持手动录入面试过程对话
- 支持展示录音转写处理状态
- 模拟面试设置页支持多选真实面试知识库
- 创建模拟面试会话时会提交 `knowledgeBaseIds`
- 已预留知识库、录音上传、手动对话录入接口

## 主要目录结构

```txt
src/
  app/                 应用入口、Provider、路由
  components/          通用组件和业务组件
  features/            业务模块 API、Hooks、Types、Mock
  layouts/             移动端布局封装
  pages/               页面级组件
  services/            HTTP、上传、SSE、语音服务
  stores/              Zustand 状态
  styles/              全局样式、变量、工具类
  types/               通用类型
  utils/               工具函数和校验规则
  mocks/               Mock 预留入口
```

## 启动指令

当前机器没有直接可用的 `pnpm` 命令，因此本项目已使用 npm 完成安装和验证。

### 安装依赖

```bash
npm install --legacy-peer-deps
```

如果你的环境已安装 pnpm，也可以使用：

```bash
pnpm install
```

### 启动开发服务器

```bash
npm run dev
```

或指定本地地址：

```bash
npm run dev -- --host 127.0.0.1
```

如果使用 pnpm：

```bash
pnpm dev
```

### 当前已启动地址

```txt
http://127.0.0.1:5173
```
