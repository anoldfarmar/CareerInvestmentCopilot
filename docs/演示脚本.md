# 职投 Copilot 复赛演示脚本

## 演示目标

让评委快速理解：职投 Copilot 不是普通简历生成器，而是一个以面试复盘为核心的求职成长系统。

## 推荐流程

1. 打开 App 首页，展示求职闭环进度。
2. 上传样例简历，展示结构化解析结果。
3. 导入样例岗位 JD，展示匹配分数、能力优势和短板。
4. 开始模拟面试，展示基于简历、JD 和历史短板生成的问题。
5. 上传样例面试录音，展示转写、结构化复盘、问题提取和改进建议。
6. 打开个人知识库，展示复盘结果如何沉淀为下一次训练数据。

## 现场兜底

- 准备已安装 APK 的备用手机。
- 准备云服务器可访问的样例数据。
- 准备后端 Mock 模式。
- 准备完整演示录屏。
- 准备本地电脑后端作为备用。
