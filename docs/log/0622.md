## 工作台热力图

### 月份切换

问题：

- 原页面只显示硬编码的「六月 / JUNE」。

- 标题没有年份，跨年查看时会不清楚。

修复：

- 在 `WorkbenchView` 中新增 `visibleMonth` 状态。

```text

```

  - 当月天数
  - 每月 1 日对应星期

涉及文件：

```text

```

### 今日定位

新增能力：

### 数据库迁移

联调时后端 `/jobs` 报错：

```text
The column `Job.salary` does not exist in the current database.
```

原因：

- Prisma Client 已按新 schema 生成。
- 但 PostgreSQL 数据库还没执行新增字段迁移。

处理：

- 先用安全 SQL 补齐字段。
- 将 migration 改成幂等写法：

```sql
ADD COLUMN IF NOT EXISTS
CREATE INDEX IF NOT EXISTS
```

- 再执行：

```bash
npx prisma migrate deploy
```

结果：

```text
Applying migration `20260622093000_add_delivery_management_fields`
All migrations have been successfully applied.
```

## 首页数据同步

问题：

投递管理页新增岗位后，投递管理页面显示已有记录，但首页漏斗仍显示 0。

原因：

- 投递管理页更新了本地 `jobs` 列表。
- 首页漏斗显示的是 `/overview` 聚合数据中的 `pipeline`。
- 新增投递后没有触发首页聚合数据刷新。

修复：

- 新增 `handleJobsChanged`。
- 投递管理页变更 jobs 后：
  1. 立即根据本地 jobs 重新计算首页漏斗。
  2. 异步重新拉取 `/overview`，刷新热力图和聚合数据。

对应提交：

```text

```
