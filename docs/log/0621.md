```text

```

## 3. Windows 只更新前端代码

Windows 本地仓库示例路径：

```powershell
D:\Study\rh\zhitouCopilot\CICopilot\CareerInvestmentCopilot-feature-initial-upload
```

进入仓库根目录，不要停留在 `frontEnd` 子目录：

```powershell
cd D:\Study\rh\zhitouCopilot\CICopilot\CareerInvestmentCopilot-feature-initial-upload
```

拉取远端最新引用：

```powershell
git fetch origin
```

只更新前端目录：

```powershell
git restore --source origin/main -- frontEnd
```

这个命令只更新 Git 跟踪的 `frontEnd` 文件，不会删除以下本地环境内容：

- `frontEnd\node_modules`
- `frontEnd\.env.local`
- `frontEnd\.npm-cache`
- `frontEnd\dist`

如果你想整仓更新，也可以执行：

```powershell
git pull origin main
```

普通 `git pull` 也不会删除 `node_modules`，但会同时更新后端代码。


```text

```

如果服务器走 HTTPS 或 Nginx 反代，则写反代后的地址：

```text
VITE_API_BASE_URL=https://api.example.com
```

## 6. 联调测试路径

1. 登录前端账号。
2. 进入「岗位匹配」页面。
3. 点击「生成岗位推荐」。
4. 检查页面是否显示：
   - 推荐岗位列表
   - 来源统计
   - 推荐层级：冲刺岗、主投岗、保底岗、不建议
   - 查看岗位、保存、备战按钮
5. 点击「保存」，确认岗位出现在「已保存岗位」列表。
6. 点击「备战」，确认跳转到面试准备页面，并带入公司和岗位名称。

## 7. 常见问题

### 前端提示无法连接后端

检查 `.env.local`：

```text
VITE_API_BASE_URL=...
```

检查服务器后端是否启动、端口是否开放、Nginx/CORS 是否允许 Windows 浏览器访问。

### 推荐接口提示 TAVILY_API_KEY 未配置

检查服务器后端根目录：

```bash
cd /home/CareerInvestmentCopilot-main/ai-job-backend
grep TAVILY_API_KEY .env
```

后端推荐接口读取的是服务器后端环境变量，不读取 Windows 前端环境变量。

### Windows 不想动 node_modules

不要删除 `frontEnd\node_modules`。使用：

```powershell
git fetch origin
git restore --source origin/main -- frontEnd
```

这个流程不会覆盖 `node_modules`。

### 只想看前端有哪些文件被更新

```powershell
git diff --name-only HEAD -- frontEnd
```

或更新前先查看远端差异：

```powershell
git diff --name-only HEAD origin/main -- frontEnd
```
