### Tavily query 过长问题

联调时后端日志出现：

```text
Query is too long. Max query length is 400 characters.
```

原因：

后端将岗位、城市、技能、可到岗状态、简历画像、平台关键词等全部拼入 Tavily query，超过 Tavily 400 字符限制，导致 Tavily 返回 `400`，前端显示 `0 JOBS`。

修复：

- 不再把长简历正文塞入 Tavily query。
- 新增 `compactSearchQuery`，将最终 query 控制在 390 字符以内。

对应提交：

```text
0b82cde fix: limit tavily job search query length
```

### 过滤招聘首页

联调后发现 Tavily 会返回公司招聘入口页，例如：

```text
https://jobs.bytedance.com/campus
https://careers.tencent.com/campusrecruit.html
```

这些不是具体岗位，不能作为推荐岗位链接展示。

修复：

- 新增具体岗位 URL 识别规则，例如：
  - `jobs.bytedance.com/campus/m/position/detail/...`
  - `careers.tencent.com/jobdesc.html?...`
  - `m.liepin.com/lptjob/...`
  - `zhipin.com/job_detail/...`
  - `shixiseng.com/intern/...`
- 新增招聘首页过滤规则，例如：
  - `jobs.bytedance.com/campus`
  - `careers.tencent.com/campusrecruit.html`
  - `campus.alibaba.com`
  - `talent.baidu.com`
  - `career.huawei.com`

对应提交：

服务器启动后端时出现：

```text
EADDRINUSE: address already in use :::8001
```

原因：

已有生产版后端占用 8001：

```text
node --enable-source-maps /home/CareerInvestmentCopilot-main/ai-job-backend/dist/src/main
```

排查命令：

```bash
ss -ltnp | grep ':8001'
```

处理方式：

```bash
kill 对应PID
cd /home/CareerInvestmentCopilot-main/ai-job-backend
npm run start:prod
```

或开发模式：

```bash
npm run start:dev
```

### 确认 Windows 是否连上服务器后端

浏览器 DevTools：

- 打开 Network。
- 过滤 Fetch/XHR。
- 登录或点击「生成岗位推荐」。
- 确认请求地址是服务器地址，例如：

```text
http://服务器IP:8001/jobs/recommendations
```

如果仍是：

```text
http://localhost:3001
```

说明 `.env.local` 未生效，需要重启 Vite。

PowerShell 也可直接测试：

```powershell
curl http://服务器IP:8001/health
```

或：

```powershell
curl http://服务器IP:8001/api-docs
```
