# CareerInvestmentCopilot

AI 求职助手项目，包含前端移动端页面和 NestJS 后端服务。

## 目录

- `front_pages/`：React + Vite + TypeScript 前端项目。
- `ai-job-backend/`：NestJS + Prisma + PostgreSQL 后端项目。
- `front_pages/FRONTEND_PROGRESS.md`：前端活文档。
- `ai-job-backend/BACKEND_PROGRESS.md`：后端活文档。

## 安全说明

真实 `.env`、API Key、依赖目录和构建产物不会提交到仓库。
请根据各项目中的 `.env.example` 或本地说明自行配置环境变量。
